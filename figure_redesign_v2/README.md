## Key Scientific Corrections vs V1

1. **Fig3 log axis**: log scale moved from displacement (V1) to residual RMS x-axis (V2); y-axis linear 0–400 mm so main point cloud is not compressed
2. **Fig4 Table3 cases**: V1 used extreme divergent dose points producing spurious 2347×/3151× ratios; V2 uses correct Table 3 cases (ratio 9.9/10.6/8.3/8.5); GA/GB/GC inset blocking curves removed
3. **Fig6 rendering**: V1 used mplot3d 3D coordinate box + displacement heatmap; V2 uses fixed 2D orthographic projection + dual-color overlay (reference grey + method color), no heatmap, no 3D box
4. **Fig6 frame labels**: V1 incorrectly labeled "Full best/worse*"; V2 correctly labels both as median-neighborhood representative frames (per p4_run.py rank 0.45–0.55 rule)
5. **Fig5 coverage**: coverage fractions (VI 100%, IV 6.4%, II 34.2%, III 28.5%) moved to caption only, not on figure
6. **Fig5 layout**: (c)(d) changed to horizontal forest plots with block-bootstrap CI

## Known Gaps

1. **Fig4 RMS values**: Table 3 RMS medians (7.95/7.70, etc.) are not stored in raw CSVs; they are the published frozen-experiment medians from the PDF, recorded as such. e_t values are independently verified against dose_response.csv.
2. **Fig4 phase map**: uses aggregated medians (30 rows, 10 reps per cell already summarized), not per-rep raw data.
3. **Fig6 ROI**: IV278 and II505 ROIs are selected by real point density and differ slightly in location (V2 spec says "prefer same部位"); both are on the main body cluster. Full point clouds retained in NPZ.
4. **Fig6 II505 view crop**: distant outlier points are view-cropped in the panorama for readability; all points retained in source NPZ.
5. **No .tex source**: manuscript files are ready-to-paste English text, not compiled LaTeX.
6. **S2 primary comparison**: Raw vs Patch per E1 pre-registration; Huber/PatchHuber not overlaid (same pattern noted in caption).
