## Rendering conventions verified

* **Same point IDs across arms.** Raw/Patch/Full read the same `Q_ref`, the
  same `display_indices.npy` (5000 pts, seed 12345) and the same point count
  (IV 9908, II 10515). No points added, no points fabricated, no smoothing, no
  outlier removal from the data arrays.
* **SE(3) effective.** Every C has det R = 1.0 to 1e-10 and orthonormal rows.
* **Transform convention locked.** `Q_method = C Q_ref`;
  `d_i = ‖C Q_ref_i − Q_ref_i‖·1000 mm`.
* **Shared camera / ROI.** All six panoramas share the fixed 2-D ortho camera
  (elev 25°, azim −60°). Within a case the three arms share one ROI mask, one
  crop, one magnification, one scale bar. Per-case ROI centres:
  IV278 ≈ (0.40, −0.10, −0.15) m half 0.09 m (476 pts);
  II505 ≈ (0.45, −0.10, −0.45) m half 0.08 m (428 pts).
* **Shared display window (verified).** Each case's window is the union of
  `Q_ref` + the three `Q_method` clouds (robust 0.5/99.5 percentile, +5% margin,
  plus an extra +4% top margin so subordinate top returns do not touch the upper
  spine). Printed limits are identical across the three arms:
  IV278 xlim=(−0.909,1.163) ylim=(−1.443,0.835);
  II505 xlim=(−0.974,1.061) ylim=(−1.456,0.604). No per-method autoscale.
* **Far-tail note.** A handful of sparse far-tail returns lie outside the view
  window (displayed-subset count: IV278=2/5000, II505=111/5000). They are kept
  intact in the `data/derived` npz (no points deleted); only not shown in this
  view, to keep the recognizable object at >70% panel occupancy.
* **No 3-D mesh box.** Plot uses 2-D `scatter` only; `Axes3D`/`projection='3d'`
  absent from `plot_figure6.py` (grep-guarded).
* **No displacement heatmap.** Dual-color overlay only (grey ref under,
  arm-color result over); no `pcolormesh`/`imshow`/colorbar.
* **Point size.** Panorama ref s=0.10 (α0.35), result s=0.13 (α0.55); inset
  ref s=0.22 (α0.50), result s=0.28 (α0.55); target print ~0.2–0.45 pt.
* **Numbers script-generated.** All e_t/e_R text and scale bars come from the
  npz/C matrices; nothing back-derived from scalar e_t/e_R.
* **No V1 mislabels.** "Full best"/"Full worse*" row labels removed; frames
  are labelled median-neighborhood representatives.
